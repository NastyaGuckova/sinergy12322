# Учет работников Университета «Синергия» (учебный проект)

Учебная программа на Python для кейс-задачи № 3 по практике.

## Возможности
- класс `WORKER` с полями: фамилия и инициалы, должность, зарплата, год поступления;
- конструктор по умолчанию и альтернативные конструкторы;
- методы изменения и отображения данных;
- вычисление стажа работы;
- поиск работников, стаж которых строго превышает введённое значение;
- отдельный модуль с описанием класса.

## Файлы
- `worker.py` — описание класса `WORKER`;
- `main.py` — ввод данных и выполнение задания.

## Запуск
Требуется Python 3.9 или новее. Откройте терминал в папке проекта и выполните:

```bash
python main.py
```

Все данные вводятся пользователем. Примеры работников, если они используются при демонстрации, должны быть условными: программа не содержит персональных данных реальных сотрудников.

## Примечание
В Python деструктор реализуется методом `__del__`, однако момент его вызова не гарантируется. В этой задаче он добавлен для соответствия формулировке задания; специальное освобождение ресурсов не требуется.
